# gpx_mcp

A planned FastMCP server for analyzing local GPX routes, tracks and waypoints and exporting stable CSV tables.

The [implementation plan](./plans/sharpen-mcp/plan.md) and [proposed tool catalog](./plans/sharpen-mcp/catalog.md) describe the planned server. This checkout contains the project scaffold and plan.

## Check the plan

```bash
python3 scripts/check_context.py
```

Run committed plans with [ralph-looper](https://github.com/dullroar/ralph-looper). See the [local guide](./docs/ralph-looper.md).
